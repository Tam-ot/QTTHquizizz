# Ôn Tập Trắc Nghiệm Quản Trị Thương Hiệu (80 Câu)

Website ôn tập nhanh bộ 80 câu hỏi trắc nghiệm môn **Quản trị Thương hiệu** (có đáp án và giải thích chi tiết theo giáo trình).

## Tính năng
- **80 câu hỏi đầy đủ**: Bao gồm phân loại chủ đề, 4 lựa chọn A/B/C/D, đáp án đúng và giải thích căn cứ giáo trình.
- **Đếm ngược 20s trả lời**: Tự động báo hết giờ nếu quá 20 giây.
- **Đếm ngược 20s xem giải thích**: Hiển thị giải thích chi tiết sau khi chọn đáp án và tự động chuyển câu sau 20 giây.
- **Nút Next (Bỏ qua giải thích)**: Chuyển ngay sang câu tiếp theo bất kỳ lúc nào (hoặc nhấn `Enter` / `Space` / `→`).
- **Âm thanh Đúng / Sai**: Hiệu ứng âm thanh trực tiếp bằng Web Audio API (có thể bật/tắt).
- **Chế độ ôn tập linh hoạt**: Đảo ngẫu nhiên câu hỏi, chuyển nhanh đến câu bất kỳ, và ôn lại riêng các câu làm sai sau khi hoàn thành.
